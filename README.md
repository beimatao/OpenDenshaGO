# OpenDenshaGO

《完全以 GPT6 Astra 撰寫的專案》

一套以瀏覽器執行的鐵路路線繪製、列車運轉與駕駛模擬原型，目標是還原經典遊戲《電車でGO!》。

使用者可以自行建立鐵道路線、設定車站、曲線、高程、速限與時刻表，將路線儲存為 JSON，並使用不同性能的列車進行實際駕駛測試。

> 本專案仍在持續開發中。不同版本的功能、路線 JSON 格式與車輛參數可能有所差異。

---

## 功能概要

目前主要功能包含：

- 路線工坊
- 直線與圓曲線繪製
- 路線自動相切
- 路線剪刀分段
- 車站建立
- 停靠站/通過站設定
- 順向/逆向運轉
- 中途站起始運轉
- 折返與循環路線
- 月台長度設定
- 海拔與坡度設定
- DEM / DTM 高程資料匯入
- 曲線與路線速限
- 時刻表計算
- 多種列車性能
- JSON 路線匯入/匯出
- 3D 駕駛場景
- 高架、地下與山岳環境
- 不同車型曲線速限判定

執行：

```text
start_windows.bat
```

如果曾經執行過舊版本，建議使用：

```text
Ctrl + F5
```

# 基本駕駛操作

常用控制：

| 按鍵 | 功能 |
|---|---|
| `W`或`↑` | 加速 |
| `S`或`↓` | 煞車 |
| `A` | 惰行、切換至N檔 |
| `Space` | 緊急煞車 |
| `H` | 鳴笛 |
| `Enter` | 開關車門 |
| `R` | 倒車切換 |
| `T` | 跳過目前停靠站 |
| `P` | 開始/暫停遊戲 |

## 遊戲目標

與《電車でGO!》相同，你可以模擬駕駛軌道列車，

在遵守速限下，將列車準點且精準地停靠目標月台。

每一個行駛段會依你的抵達時間和停靠位置做評分，滿分100分。

所有行駛路段的平均即是你的最終成績。

## 遊戲模式

模式有`簡單模式`和`經典模式`兩種：

`簡單模式`會顯示「常用全煞車停止距離」及「等速推估時間」，方便新玩家上手，
月台停靠允許誤差加大至前後20m。

`經典模式`更趨近《電車でGO!》，月台停靠允許前後10m誤差。

## 遊戲設計

你可以`W`或`↑`提高檔位，`S`或`↓`降低檔位，

P檔位為牽引檔位，可讓列車加速，從P1開始，最高五檔到P5。

B檔位為制動檔位，可讓列車減速，從B1開始，最高八檔到B8。

N檔位為惰行檔位，列車引擎及煞車空轉，此為初始檔位。

檔位切換如下：`B8`→`B7`→...→`B1`→`N`→`P1`→`P2`→...`P5`

---

你可以按`Space`進行緊急煞車，

該列車以最大緊急煞車進行劇烈的減速。

此時檔位強制鎖在`EB`，在完全煞停前無法換檔。

完全煞停後可按`X`解除緊急煞車，恢復一般檔位切換。

---

你可以按`R`進行倒車，

倒車時最大速限限制在5km/h。

常用於停靠月台過頭時使用。

---

停靠月台完成後，請按`Enter`開啟車門並結算。

下方文字會顯示站點停靠時間，倒數結束後才能發車。

發車前請再按`Enter`關閉車門。

若提早到站，會增加倒數時間至正常離站時間。

表定抵達/表定通過會顯示允許列車停靠/通過時間誤差。

時間超過誤差範圍外時，每超過/提前0.1秒，該段行駛分數扣0.1分。

停靠月台每誤差1cm，該段行駛分數扣0.1分，扣分上限50分。

---

停靠月台時，可按`T`跳過停站時間，

直接將時間快轉至發車前5秒。

---

你可以按`P`暫停遊戲。

畫面縮小或進入背景超過3秒會自動暫停遊戲。

0.1.6版本包含下列主要車型：

| 車型 | 編組 | 最高速度 |
|---|---:|---:|
| 台北捷運 C381 | 6 輛 | 80 km/h |
| 台鐵 EMU3000 | 8 輛 | 130 km/h |

不同車型不只是最高速度不同。

模擬亦會使用各車型不同的：

- 最高速度
- 加速度
- 常用煞車
- 緊急煞車
- 車身長度
- 曲線性能
- 傾斜相關參數

E5 另具有車體傾斜相關設定。

車輛資料由：

```text
trains.json
```

管理，因此後續可新增或修改列車性能。

# 路線工坊

## 建立新路線

進入路線工坊後，可以先設定：

```text
路線名稱
列車種類
運轉方向
駕駛模式
```

再開始繪製軌道。

---

## 直線

在地圖中指定連續節點即可建立直線軌道。

系統會依軌道幾何自動計算：

- 線段長度
- 累積里程
- 軌道方向

---

## 圓曲線

路線支援直線與圓曲線組合。

系統可處理相鄰路段的相切關係，使直線與曲線之間的方向較為連續。

曲線會記錄：

```text
曲線方向
曲線半徑
曲線長度
里程位置
```

曲線半徑同時會影響列車最高允許速度。

---

## 軌道剪刀分段

既有軌道路段可以重新切分。

用途包括：

- 插入控制點
- 加入車站
- 調整曲線
- 修改高程
- 修正部分軌道

分段時會盡量保留原本的：

- 曲線資料
- 里程
- 高程資料

因此不需要重新建立整條路線。

---

# 車站設定

在指定軌道位置加入車站。

每個車站可設定：

```text
車站名稱
停靠/通過
月台長度
停站時間
預定到達時間
```

---

## 停靠與通過

車站可以設定為：

```text
停靠
```

或：

```text
通過
```

設定為通過站後：

- 不進行停車減速
- 不執行停站時間
- 時刻表會重新計算

因此同一條路線可依站點停靠調整成不同運轉模式，例如：

- 普通
- 快速
- 特急
- 新快速

---

## 月台長度

月台長度可手動輸入。

如果留白，系統可依列車長度與模式自動產生適合的月台長度。

簡易模式：

```text
列車長度 + 40 m
```

經典模式：

```text
列車長度 + 20 m
```

如果手動設定的月台比目前列車短，系統會顯示警告。

---

# 海拔與坡度

路線除了平面位置，也可以設定軌道高程。

可用於建立：

- 地面線
- 上坡
- 下坡
- 高架
- 地下
- 山區鐵路

系統會依相鄰軌道高程計算坡度。

`地面`：軌道沿地形高低起伏。

`地下`、`高架`：軌道依地形高低向上、向下偏移一定距離。

`絕對高程/穿山`、`切換坡道`：可指定坡道頭尾的「絕對海拔高度」，兩端直接拉軌道直線。(兩者實際功能相同)

`緩坡`：可指定坡道頭尾的「絕對海拔高度」，但頭尾兩端採曲線過度。

# DEM / DTM 高程資料

可透過 GIS 資料取得較真實的地形高程。

基本流程：

```text
Train Simulator
       ↓
匯出 GeoJSON 採樣點
       ↓
QGIS
       ↓
DEM / DTM / GeoTIFF
       ↓
Sample Raster Values
       ↓
匯出高程資料
       ↓
Train Simulator
```

QGIS 匯出的資料需要保留沿線里程欄位與高程欄位，例如：

```text
s
SAMPLE_1
```

系統即可依：

```text
里程
→
高程
```

建立沿線高程。

---

# 時刻表

車站可以設定預定時間。

系統亦可依：

- 路線距離
- 車輛性能
- 最高速度
- 曲線速限
- 停靠站
- 停站時間
- 加速
- 煞車

估算運轉時間。

---

# 中途站起始

列車可以直接由路線中的中途站開始。

適合用於：

- 特定區間測試
- 車站進出站測試
- 曲線測試
- 坡度測試
- 長距離路線除錯

---

# 順向與逆向

同一條路線可以進行雙向運轉。

逆向模式會重新處理：

- 車站順序
- 距離
- 速限
- 停靠站
- 時刻表

---

# 折返與循環路線

可建立：

- 一般端到端路線
- 中途折返
- 終點折返
- 循環路線

適用於捷運、環狀線、區間車等不同運轉方式。

---

# 路線 JSON

完成路線後，可以匯出 JSON。

JSON 主要保存：

```text
軌道
曲線
車站
里程
高程
速限
停靠設定
時刻表
運轉方向
路線相關設定
```

之後可以重新匯入並繼續修改。

# Google 3D 預覽

部分版本支援 Google Photorealistic 3D Tiles / Cesium 類型的實景預覽。

此功能屬於選用功能。

使用時需自行準備：

```text
Google Cloud Project
Google Maps Platform Billing
Map Tiles API
API Key
```

請勿將 API Key 上傳至公開 GitHub Repository。

建議加入 `.gitignore`：

```gitignore
.env
config.local.*
```

目前 Windows 一般功能已完成實機測試；Google 3D 預覽功能仍建議另外進行 API 實機驗證。
