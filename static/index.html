讀取沿路線的地面高程斷面（不是平面等高線圖）。GeoTIFF 需包含實際高程與地理定位；首次使用請執行 install_dtm_support.bat。單檔上限 2 GiB，大檔請先裁切。

依距離平滑，100 m 是可調整的起始值；會改變貼地／高架／地下的軌道高度。絕對高程與坡道參數保留，但接續起始高度可能隨前段改變，套用後請檢查高程銜接。

保護站點、手動限速和高度模式分界；固定絕對高度可保留高程折點合併；坡道／緩坡段不合併。簡化會改變里程與曲線限速，同步對應地形，並清空抵達秒數供重新排時。

橘色虛線為預覽；原資料尚未變更。套用後可按復原。

地形高程交換（KML／QGIS DEM）

匯出路線不會自動產生真實高程。KML 可於 Google Earth Pro 看剖面；GeoJSON 採樣點請在 QGIS 用 DEM「Sample raster values」取高程，再匯出 CSV 回來。請保留 s 欄位，地面高程以公尺為單位。

轉換成功會下載 s,z CSV 並套用地形；可復原。貼地／相對高程路段隨地形變化，固定高程路段保留軌道高度。匯入後請檢查坡度並重算時刻。

CSV 欄位 s,z：水平里程 m、高程 m。需與軌道使用同一高程基準；未提供地形時採 0 m 平地，不能推斷真實山脈。

03 / 區段幾何與高度

R=0 為直線；正值右彎、負值左彎；弧長 L=|R|×角度（弧度）。高度不連續時必須插入切換坡道。貼地模式偏移固定 0，地下／高架可選深度。絕對高程與坡道可指定起點、末端高程。固定高程保留區段內坡形；手動改起末高程會改為兩端直線坡。接續繪線自動沿前段切線銜接，終點會吸附到可行線形。緩坡使用平滑 S 形高度過渡，填寫末端絕對高程。

04 / 停靠站與時刻表

可用「設定起始站 S」點選路線，或填寫中心里程。起始站需在第一站之前，兩端需預留至少半個車長。反向班次從順向最後一站月台出發，終停此站；逆向時刻依難度重新計算。

X 是月台正中心；順向車頭停車線＝中心＋半個車長，逆向為原里程中心－半個車長。月台長度留白＝車長＋前後容許距離（簡單各 20 m、經典各 10 m，可修改）；開門仍須停妥、全車在月台內且在模式容許範圍。手動月台太短會提醒。「停站／過站」切換會覆寫所有抵達秒數，依目前難度重算；過站忽略停留秒數。下表為順向時刻，逆向班次自動另算。

駕駛指南

W / S 調整單一控制桿：B8 … B1 → N → P1 … P5。先減至 N，再繼續按 S 才會制動。空白鍵緊急煞車；停妥按 X 解鎖。

接近車站時依停距提早煞車。停車後可按 R 倒車微調（限 5 km/h），按 Enter 開門結算。誤差正值代表超過，負值代表未達。開門容許範圍依模式設定，且全車須在月台內。過站自動記錄通過時刻，不必開門。反向行駛按鈕會重開逆向班次；R 仍是低速倒車微調。

開門後至少停留指定秒數，早到時需等到表定時間加停留秒数；再按 Enter 關門。開門等待時可按 T 跳至發車前 5 秒，倒數後仍須 Enter 關門並自行加速。準點容許值在路線工坊調整，預設早晚各 30 秒。

限速取車型、全車所佔軌道限速與曲線限速最小值。曲線公式 v=√(容許橫向加速度×R)，這是遊戲簡化模型，不是實際鐵路設計標準。同向連續彎道組採最低速限，短於一個車長的同向曲線間直線視為連接段。提速點距下一降速點不足全車長時維持前一低速；前方距離尺與實際判定共用整理後速限，解限仍須等全車通過。經典模式隱藏等速推估及估計停距，並使用經典模式開門容許範圍。前方降速會警示，不會自動煞車。超過車型事故門檻即脫軌；移動撞到路線頭尾止擋也會遊戲結束。門檻為遊戲設定，車型資料可查。

Google 實景需啟用 Map Tiles API 的瀏覽器金鑰與計費帳戶。金鑰只保留在本頁記憶體。需自行設定 HTTP referrer／API 限制與預算；3D 覆蓋、畫質和近地面效果因地區而異。高度由路線提供，不會自動從 Google 模型擷取地形。

背景視窗／離線超過 3 秒會自動暫停。預估抵達＝剩餘距離÷目前速度，不包含後續加減速。
